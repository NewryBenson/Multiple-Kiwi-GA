# Multiple-Kiwi-GA
Genetic Algorithm in Python for Fastwind.

The base Kiwi-GA code is presented in Brands et al. (2022): 
"The R136 star cluster dissected with Hubble Space Telescope/STIS. 
  The clumped winds of the most massive stars", A&A, 663, A36
  
 Link to journal: https://www.aanda.org/component/article?access=doi&doi=10.1051/0004-6361/202142742
 
 DOI: https://doi.org/10.1051/0004-6361/202142742

This code was extended to be able to fit multiple systems as part of a master's thesis by Van den Eynden, S. (reference tba)
  
A manual can be found in the main directory: manual_Kiwi_GA.pdf. This manual is somewhat outdated and does not include the changes made in this fork.

The example input included here does follow the updated format required by mutiple kiwi ga.
